# Small reference datasets

- `state-*.csv`: source tables of Jake VanderPlas, *Python Data Science Handbook*, merge-and-join chapter (extra 15 and Notebook 3), from https://github.com/jakevdp/PythonDataScienceHandbook/tree/master/notebooks/data
- `planets.csv`: unchanged copy of https://github.com/mwaskom/seaborn-data/blob/master/planets.csv, retrieved 14 October 2026. The seaborn example dataset of the grouping chapter (extra 14); Notebook 3 reads this copy, so teaching does not need a live download.

The Berlin data are prepared separately with `case-study/prepare_airbnb.py` and are not bundled here.
