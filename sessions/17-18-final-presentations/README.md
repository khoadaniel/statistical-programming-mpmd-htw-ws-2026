# Sessions 17–18 · Final project presentations

The last two sessions are reserved for the presentations of the seven teams: four teams in Session 17, three in Session 18. All teams present their solution of the same project, the leaderboard task. The brief, milestones, rules and assessment criteria are in [final-project.md](final-project.md).

> **Format.** 15 minutes of presentation with a live demonstration, then 10 minutes of questions, including individual questions to each member. Have a recorded fallback ready in case the live demonstration fails.

## Checklist one week before

- [ ] Repository complete: README with setup instructions, reproducible data loading, tests passing in CI
- [ ] Service with the top-3 headings and dashboard running together with Docker Compose, released through the CI/CD workflow; monitoring plan and model card in the repository
- [ ] Final submission (round L3) reproducible from the tagged repository
- [ ] Every member has a part of the presentation and has reviewed at least two pull requests of others
- [ ] Rehearsed once with a timer (15 minutes)
- [ ] AI-use declaration added to the repository
