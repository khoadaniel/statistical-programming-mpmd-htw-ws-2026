# Session 0 · Playground

> A notebook to try things out: NumPy, pandas and the Berlin Airbnb data are loaded, the rest is yours.

[Open the playground](playground.ipynb)

- Run the first cells once: they set the working folder, import NumPy and pandas and load the Airbnb files.
- Below them is empty space. Try the code from the lecture notebooks on the real data, change it, break it.
- Nothing here is graded, and nothing here is saved anywhere but your own laptop.

## Setup

The Airbnb data must be unzipped into `case-study/data/airbnb/` ([getting the data](../../case-study/README.md#getting-the-data)).
