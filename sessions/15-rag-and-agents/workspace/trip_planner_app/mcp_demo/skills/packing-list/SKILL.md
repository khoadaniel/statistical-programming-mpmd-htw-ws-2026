# Packing list

1. Take the forecast from `weather_forecast` for the trip dates only.
2. Warm layer: pack a jacket if any day has a minimum below 10 °C; add a hat and gloves below 2 °C.
3. Rain: pack a rain jacket or an umbrella if any day has a rain chance of 50 % or more.
4. Sun: pack sunglasses if every day has a rain chance below 20 % and a maximum above 15 °C.
5. Write the list in at most 4 lines and name the number from the forecast that decided each item.
6. If the forecast failed, say so. Do not invent the weather.
