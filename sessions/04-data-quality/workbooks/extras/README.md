## Data

Inside Airbnb (2026), *Berlin, Germany*, snapshot of 26 June 2026, CC BY 4.0, https://insideairbnb.com/get-the-data/. The block notebooks read `case-study/data/airbnb/`. The lecturer prepared these data (personal data removed, 20 % of the listings held back as a test set), and you download them as `airbnb-v1.zip` from the course drive (see [case-study/README.md](../../../../case-study/README.md)). The data are not stored in this folder. The Airbnb data come from public listing pages; the materials report them in aggregate and never name hosts, and the preparation script removes names typed into the registration field. Block 2 uses the wine dataset shipped with scikit-learn (UCI Machine Learning Repository). The cleaned table of block 2 is written to a temporary folder, or to the path in `AIRBNB_CLEAN_OUT`.
