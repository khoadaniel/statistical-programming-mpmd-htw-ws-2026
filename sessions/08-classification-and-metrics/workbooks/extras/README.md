On 2026-10-14 the course-written notebooks of the earlier version of this session were folded into the two block notebooks and deleted (they remain in the git history): the lecture notebook `04-lecture-scores-thresholds-and-rare-classes.ipynb`, the case studies `03-case-study-churn-pipelines.ipynb`, `06-case-study-churn-threshold-and-calibration.ipynb` and `07-case-study-imbalance.ipynb`, the exercise notebook `session-08-exercises.ipynb`, and the extra `10-class-imbalance-in-depth.ipynb` (the former imbalance lecture of Session 9).
