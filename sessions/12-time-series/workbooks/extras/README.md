## Running the extras

Extras 01, 04, 05, 06, 08 and 09 run in the course environment. Extras 03, 07 and 10–13 need StatsForecast, MLForecast or skforecast, which do not support pandas 3 yet; the session README's Setup has a `uv run --no-project` command that opens them in a temporary environment. With the library versions of October 2026, one cell of extra 12 (a number format) and the error-metric cells of extra 10 (a duplicated `cutoff` column) fail; the rest runs. Extra 02 is a reading copy (see above). Several extras download their example data (CO₂, air passengers, M4, bike sharing from OpenML, skforecast datasets) when they run.
